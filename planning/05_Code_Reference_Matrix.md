Code selection cannot follow a filename or fluid name alone. Preserve the approved construction/in-service code and edition on each evaluation. Do not substitute II-D allowable stress for pipeline strength inputs. Do not treat a pressure-only thickness as a universal structural minimum. Local pitting, repairs, external pressure, loads and unsupported components require separate applicability decisions.

Each future rule record must contain source clause/table and edition, scope exclusions, equation and variable definitions, unit contract, notes/factors, input validation, rounding policy, numerical limits, error states and independent expected examples. Property extraction requires visual checking of table headings, continuation pages and notes. Current text indexes are insufficient to authorize a production material database. Confirm permitted distribution before bundling proprietary reference content.
