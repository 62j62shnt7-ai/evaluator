# Acceptance criteria and limitations

A01 Copied sources match original SHA-256 and ZIP contents pass integrity check.
A02 Both sample workbooks have independently reviewed expected observations and region inventories; every region is imported, excluded with reason, or unresolved.
A03 Date conflict in Separator UT 10-2026 is detected; no rate uses an unresolved date.
A04 Image-only 2010 content is reported and reviewable; successful empty extraction is prohibited.
A05 Repeated headers, merged cells, scattered blocks, hidden sheets, formulas without caches, external links and unit mixtures have fixtures.
A06 Current-only and historical-only locations survive comparison; no missing measurement becomes zero.
A07 Replacement/build-up and ambiguous location matches block unsupported historical pairing.
A08 Negative rates, zero elapsed time, severe loss and missing required inputs have explicit statuses; no silent fallback.
A09 Bulk approval preview shows exact scope, exclusions and impact; mixed bases split groups; undo and audit recover every adopted value.
A10 Independent engineering benchmarks cover each equation, geometry, unit system, interpolation rule and applicability boundary; documented tolerances and qualified reviewer sign-off are required.
A11 Reports expose source provenance, rule edition, assumptions, unresolved items and evaluation revision. Import acceptance is separate from equipment integrity approval.
A12 Portable build runs on a clean disconnected supported Windows machine, with backup/restore and no external runtime assets.

Current limits: TL-B, API 570 and B31.3 unavailable in searched locations and referenced chat attachments list is empty. Actual two-workbook comparison remains blocked. Cell/object inventories are structural evidence, not a visually certified reading inventory. openpyxl warns that DrawingML support is incomplete and that one print-area definition is invalid (#N/A). Existing workbook engineering formulas, previews and conclusions are unverified historical artifacts. PDF text review is scoped discovery, not equation validation or licensing clearance. No engineering calculation or equipment disposition is validated here.
