# Start here

This folder contains the UT Inspection Evaluator and its original engineering references and workbooks.

Double-click **Run UT Review.command** (macOS) or **Run UT Review.bat** (Windows). The default page is the three-screen, single-workbook batch workspace. See README.md for the workflow and engineering limitations.

The 5 November 2026 redesign is documented in planning/16_Revamp_Audit_and_Delivery.md. Its implementation plan is docs/superpowers/plans/2026-11-05-ut-revamp.md. Historical plans and IMPLEMENTATION_STATUS.md remain available for prior decisions; their older default-UI descriptions are superseded by the current README.

Preserve original source files. Calculations remain DRAFT / NOT VALIDATED and cannot establish equipment fitness. Run the tests and actual-workbook acceptance before claiming a completed change.
