# Start here

Double-click **Run UT Review.bat** on Windows or **Run UT Review.command** on
macOS. Open [localhost:8765](http://127.0.0.1:8765/) if the app does not open
a browser. The launcher uses a separate default project. To open the gathered
preview snapshot, use the command in [Local files and verification](docs/local_files.md).

Start in **Workbook library** and select your UT comparison sheet. In
**Inspection grid**, check the matched readings, set the code basis, and fill
materials and other inputs. Click **Calculate ready locations** to open the
read-only **Calculations** tab, then use **Download Excel (.xlsx)** when
you’re ready. See [README](README.md) for the full workflow and
[Implementation status](IMPLEMENTATION_STATUS.md) for the current scope.

Engineering outputs remain **DRAFT / NOT VALIDATED**.
